# 🚀 Antigravity Git Commit Protocol

When pushing changes to Git, perform high-quality commits following these rules:

1. **Format**: Separate subject from body with a blank line.
2. **Subject Line**: 
   - Limit to 50 characters.
   - Capitalize the first letter.
   - Use the imperative mood (e.g., "Add", "Fix", "Update").
   - Do not end with a period.
3. **Body**:
   - Wrap at 72 characters.
   - Explain **what** and **why** instead of **how**.
